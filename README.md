Este proyecto es una aplicación de consola desarrollada en Python que permite gestionar un inventario de productos utilizando una base de datos SQLite.
Fue desarrollada como entrega final del curso y cumple con todos los requisitos obligatorios establecidos.

Tecnologías utilizadas
* Python 3
* SQLite3 – base de datos embebida
* Colorama – personalización visual de la interfaz (colores en la terminal)

Estructura del proyecto
* inventario.db        # Base de datos (generada automáticamente)
* EntregaFinal.py      # Código fuente principal
* README.md            # Documentación del proyecto
